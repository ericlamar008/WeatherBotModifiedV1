# Atmospheric Station Telemetry & Ensemble Calibration

Internal meteorological verification toolkit for multi-model ensemble temperature forecasts (GFS, ECMWF, ICON) against airport METAR / SYNOP station observations.

## Modules

- Station bias & regime calibration (`forecasting.py`)
- Diurnal temperature range verification (`resolution.py`)
- Automated telemetry aggregation

## Local Run

```bash
npm install
npm run dev
```
